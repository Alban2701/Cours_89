OBJECTIF DU PROGRAMME ET DESCRIPTION DU MODULE

⚪ 1. Objectif du programme

Développer la capacité à collecter, structurer, stocker, interroger et exploiter des données afin de concevoir des solutions data fiables et adaptées à un besoin professionnel.

⚪ 2. Description du module

Le module couvre les formats de fichiers plats (CSV, JSON, XML), la modélisation relationnelle et la normalisation, les requêtes SQL, les principales familles NoSQL, les formats binaires et la compression. Il conduit les étudiants à choisir une solution de stockage adaptée, puis à concevoir une chaîne de données complète dans le cadre d’un projet de streaming musical.
Projet intégrateur : StreamData — Concevoir la chaîne de stockage d’une plateforme de streaming musical. Les étudiants extraient des données musicales, les modélisent et les interrogent en SQL, puis proposent un export NoSQL justifié.
