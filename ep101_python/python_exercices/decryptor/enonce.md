# Decryptor

Un programme qui permet de sélectionné un algorithme de chiffrement et un message chiffré, et affiche le message déchiffré

## Objectif

Le programme va demander l'algorithme qui aura servi à chiffré le message (ce sont les mêmes que l'exercice "Encryptor") ainsi que les clé de déchiffrage et affiche le message déchiffré.

## Contrainte

- Le message chiffré ne doit contenir que des caractères ascii.
- Les algorithmes de chiffrement ne modifient par défaut que les caractères alphabétiques. La casse des caractères restent inchangés.
- Partez du principe que l'utilisateur n'est pas bête. Il n'y a pas besoin de valider les entrées utilisateurs.
- Vous pouvez créer autant de fichiers que vous le souhaitez.
- Vous pouvez reprendre du code du projet Encryptor
- Vous pouvez utiliser d'autres librairies, tant que les algorithmes de chiffrement eux-mêmes sont codés par vous

## Bonus

Codez également le déchiffrage des algos qui fonctionnent en ASCII !
